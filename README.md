# TG_2_Obsidian

Telegram-бот с AI-агентом для Obsidian через Obsidian Local REST API.
Создаёт заметки, дополняет и правит существующие, автоматически располагает
их внутри хранилища, ставит связи и обрабатывает ошибки API/сервера.

Документация: [docs/README.md](docs/README.md).
Функциональные требования: [docs/FEATURES.md](docs/FEATURES.md).

LLM работает через пул аккаунтов и моделей: при исчерпании лимита на одном
API запрос уходит на следующий аккаунт, затем на следующую модель по
качеству, а после всех лимитов срабатывает автосброс к начальным условиям.
Пока используются заглушки (`LLM_STUB=true`). Подробности —
[docs/LLM_POOL.md](docs/LLM_POOL.md), состояние в боте — `/llm`,
ручной сброс — `/llm_reset`.
