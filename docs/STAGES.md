# История этапов

Проект строился по этапам: один этап — законченная порция работы, один
md-файл в `docs/`. Здесь — оглавление всей истории, чтобы не искать её по
папке. Каждый файл этапа отвечает на вопросы «что сделано», «почему так»,
«как проверить» и «как откатить», а не только «что добавили».

Номера файлов не всегда совпадают с номером этапа: файлы создавались по мере
роста `docs/`, и позже часть этапов шла вне исходного плана. Ориентируйтесь на
таблицу ниже.

## Про этап 12

Этап 12 задумывался как переезд на NAS. Пока NAS нет, он **опционален**:
Docker-образ с `restart: unless-stopped` уже даёт автозапуск, для HTTPS
добавлена настройка `OBSIDIAN_VERIFY_SSL`, а `deploy/tg-obs.service` —
юнит systemd для запуска без Docker. Всё, что нужно сделать при переезде,
описано в [16_ci_docker.md](16_ci_docker.md#перенос-на-nas-этап-12-опционально).

## Решения

метрики и графики, публикация образа в GHCR с автообновлением, несколько
